# CIMOL Hub — Pusat Informasi Kelas C IFUMMI 25

Selamat datang di **CIMOL Hub**, aplikasi resmi **Kelas C IFUMMI 25** yang dirancang untuk mempermudah koordinasi, komunikasi, dan pengingat sehari-hari seluruh anggota kelas.

Tersedia sebagai **Aplikasi Android** dan **Web App (PWA)** yang bisa diakses langsung dari browser.

---

## Apa yang Bisa Dilakukan CIMOL Hub?

### Untuk Mahasiswa
- **Jadwal Kuliah** — Lihat jadwal harian dengan info jam, ruangan, dan dosen pengampu.
- **Tugas & Deadline** — Pantau semua tugas individu maupun kelompok lengkap dengan countdown deadline.
- **Pengumuman Kelas (Mading)** — Baca pengumuman terbaru langsung dari halaman beranda.
- **Struktur Organisasi** — Lihat susunan pengurus dan anggota kelas.
- **Notifikasi Otomatis** — Dapat pengingat sebelum jadwal kuliah dimulai dan sebelum deadline tugas habis.
- **Notifikasi Kelompok** — Pengingat presentasi khusus untuk kelompokmu, tidak tercampur dengan kelompok lain.

### Untuk Pengurus Kelas (Admin)
- **Dashboard Admin** — Kelola semua data kelas (jadwal, tugas, mading, mahasiswa, notifikasi) langsung dari browser.
- **Push Notifikasi Kustom** — Buat dan kirim pengumuman penting ke semua anggota atau ke mahasiswa tertentu saja.
- **Panel Debug** — Pantau status pengiriman notifikasi dan reset data jika diperlukan.

## Cara Menggunakan

### Versi Android
1. Unduh file APK dari halaman [Releases](https://github.com/XanderID/CIMOLHub-IFUMMI-25/releases).
2. Install di perangkat Android kamu (aktifkan "Izin dari sumber tidak dikenal" jika diminta).
3. Buka aplikasi -> Pilih profil kamu -> Izinkan notifikasi.
4. Selesai! Notifikasi jadwal dan tugas akan aktif secara otomatis.

### Versi Web (PWA)
1. Buka link aplikasi di browser (Chrome direkomendasikan).
2. Pilih profil kamu di halaman Setup.
3. Izinkan notifikasi browser jika diminta.
4. Untuk pengalaman terbaik, install sebagai PWA (klik "Tambahkan ke layar utama" di browser).

---

## Catatan Penting

- Notifikasi di Android membutuhkan izin notifikasi yang diaktifkan di pengaturan perangkat.
- Data kelas disinkronkan otomatis dari database kelas, tidak perlu update manual.
- Jika ada data yang salah atau fitur yang tidak berjalan, hubungi admin kelas atau lapor ke @XanderID.
